## ส่วนที่ใช้ต่อในครั้งที่ 3

คัดลอก **Entry และ Exit Criteria ของทีม** จากใบงานครั้งที่ 1 มาไว้ตรงนี้ด้วย เพื่อให้หาง่าย

| ประเภท | เกณฑ์ของทีม |
|---|---|
| Entry | ระบบ ณ commit ที่ระบุติดตั้งบนเครื่องทดสอบกับ MySQL 8.0 InnoDB ตรวจพบ CHECK ยอดคงเหลือไม่ติดลบ และชุดทดสอบอัตโนมัติเดิมผ่านครบ |
| Entry | มีบัญชีทดสอบครบ 3 บทบาท คำสั่งซื้อรอจ่ายอย่างน้อย 20 ใบ (มี 1 ใบที่รายการที่สองยอดไม่พอ) และบันทึกยอดตั้งต้นของทุกสินค้าไว้ |
| Exit | AC-07 และ AC-08 ผ่าน 100%: คำขอพร้อมกัน 2 คำขอต่อใบ ซ้ำ 20 รอบ สำเร็จ 1 ได้ 409 อีก 1 ทุกรอบ · สต็อกไม่พอแล้วยอดและสถานะเท่าเดิม 0 แถวเคลื่อนไหว |
| Exit | หลังจ่ายครบ 20 ใบ ยอดในระบบ = ยอดตั้งต้น − ที่จ่าย ทุกสินค้า ไม่ติดลบ และไม่มีข้อบกพร่องระดับสูงของ UC-07 ค้าง |

## ทีมที่ยังไม่มีเอกสารออกแบบของโครงงาน

วาดภาพส่วนประกอบจากโค้ดหรือแผนที่มีจริง แล้วติดป้ายว่า “สร้างย้อนหลัง” หรือเขียนช่องว่างว่าขาดเอกสารใด ใครรับผิดชอบ จะได้เมื่อไร · ห้ามแต่งข้อค้นพบที่ไม่ได้ตรวจจริง
